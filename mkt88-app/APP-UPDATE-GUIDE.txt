MKT 4D - HOW APP UPDATES WORK NOW
=================================

1) WEBSITE / RESULT / DESIGN CHANGES  ->  NOTHING TO DO
   The app shows the live website (https://www.mkt88.my) inside the app.
   Any change to results, colours, new games, new pages, past-result filters
   is live in the app the moment it is published. No new APK, no download.

   Examples: new draw data, layout changes, new menu items, 6D results,
   AdMob/AdSense changes on the web side, bug fixes on the website.

2) NATIVE APP CHANGES  ->  THE APP UPDATES ITSELF
   Only these need a new build: app icon, app name, Android permissions,
   new Android plugin, Play Store metadata.
   When that happens, the app now shows:
       "Update available - MKT 4D 2.x is ready to install."
       [ Update now ]   [ Later ]
   Tapping "Update now" downloads the new version inside the app and hands it
   straight to the Android installer. The user never needs an APK link again.

HOW TO SHIP A NATIVE UPDATE (for the developer)
-----------------------------------------------
   a. mkt88-app/android/app/build.gradle  ->  bump versionCode (+1) and versionName
   b. build:  gradlew assembleRelease bundleRelease
   c. copy the new APK to  public/mkt88-4d-v<version>.apk
   d. add a header rule for it in  next.config.mjs
   e. update  public/app-version.json  with the new versionCode, versionName,
      apkUrl and short notes  (the app reads this file)
   f. commit + push  ->  Render deploys  ->  every installed app sees the prompt

   IMPORTANT: always publish the new APK and app-version.json in the SAME
   commit, so nobody is offered a file that is not there yet.

FILES
-----
public/app-version.json          the update manifest the app checks
public/mkt88-4d-v2.4.apk         current public download
mkt88-app/mkt88-4d-v2.4.apk      local copy (same file)
mkt88-app/mkt88-4d-v2.4.aab      upload this to Google Play Console
mkt88-app/android/keystore/      signing key - NEVER lose this
